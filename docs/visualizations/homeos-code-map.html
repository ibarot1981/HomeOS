HomeOS Version 0.4 Code Map

A small, verified implementation map for firmware/src/main.cpp.

setup()
Prints diagnostics, starts button inputs, then starts HomeOS.
↓
ClockModule + StatusModule
Static two-entry registry; activeModuleIndex selects the current module.
↓
drawActiveModule()
Initializes the verified ePaper driver, calls the current module draw method, then hibernates. Full refresh only.
↓
loop()
scanButtons(now) preserves active-low GPIO4/GPIO5/GPIO6 inputs and 50 ms debounce. Previous/Next wrap modules; Select redraws. activeModule().update(now) lets Clock perform WiFi/NTP retry and minute refresh.

Scope boundaries

No scheduler, plugin system, settings, long press, partial refresh, fast refresh, or additional modules are implemented.
