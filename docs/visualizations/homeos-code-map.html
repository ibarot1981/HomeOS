Hardware boundaries

Inputs: Previous GPIO4, Select GPIO5, Next GPIO6. Each is active-low with an internal pull-up.

Output: Waveshare 4.2-inch black-and-white SPI ePaper: BUSY GPIO7, DC GPIO8, RST GPIO9, CS GPIO10, MOSI GPIO11, SCK GPIO12.

External: optional local WiFi credentials connect to WiFi and NTP time sources. Credentials are stored only in ignored firmware/include/config.local.h.
